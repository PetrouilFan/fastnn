# Archived documentation

These documents describe the 2.x/3.0 surface, which was archived at tag
`archive/3.0`. They are kept for the measurements and the reasoning they record,
not as instructions: `docs/archive/reference/` names classes that no longer
exist, and every command in `docs/archive/guides/` targets a binary that was
removed.

The current documentation lives in `docs/v3/`, `docs/internals/` and
`docs/quickstart-fn3.md`.

`docs/archive/reports/` holds the 3.0 measurement records (fn3 ledger reports,
parity and performance runs) and `docs/archive/internals/` the 2.x architecture,
ARM, roadmap and legacy-boundary notes. Both are evidence and history: the
commands in them name binaries and benches that no longer exist.
